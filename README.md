# install_dev_tools.sh


#### Install dev tools on Debian based system and create python venv with preinstalled packages (Django) and write logs to file.

### Tested on:
    Distributor ID: Debian
    Description:    Debian GNU/Linux 12 (bookworm)
    Release:        12
    Codename:       bookworm


### Usage:
    chmod u+x install_dev_tools.sh
    ./install_dev_tools.sh

### Config:
    TOOLS_TO_INSTALL (array)
    PYTHON_TOOLS (array)
    PYTHON_VENV_PATH (string)
    LOG_FILE (string)
